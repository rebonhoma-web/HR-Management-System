# نظام إدارة الموارد البشرية (HR Management System)

منصة متكاملة ومؤتمتة لإدارة الموارد البشرية تهدف إلى تسهيل العمليات الإدارية، متابعة الموظفين، إدارة الإجازات والرواتب، وربط لوحة تحكم الويب بتطبيق الموبايل لتقديم تجربة استخدام سلسة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Backend & Web API:** Laravel (PHP) & MySQL
* **Mobile Application:** Flutter (Dart)
* **Design & Analysis:** UML Diagrams, ERD, & Figma UI Mockups
